## 陪练艇避碰

赛场上有一艘陪练艇沿环路巡航（不主动避让）。与它交会时，裁判按练习规则判定避让责任：

- 异舷相遇，左舷受风的一方让路；同舷相遇，上风艇让路。
- 刚换舷取得优先的一方，必须给对手留出至少一条凭当时舵、帆和速度能走通的无碰路线。
- 让路方只剩触礁、出界或撞船路线时，优先方不能用碰撞一刻的船位免责。

每次交会按"避让义务形成 → 避让机会耗尽 → 实际接触"记录证据并给出判定；
你全责时罚时 +8s，对方全责不罚，证据不足留作争议。回看航次可在事件列表中
复查完整证据链，海图上点击事件可定位事发位置。

```sh
npm run verify   # 用两次交会（贴边后突然换舷 / 对手有安全出口未转舵）等场景验证裁判判定
```
